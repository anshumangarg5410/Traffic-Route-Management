# Frontend Assets Directory

Asset organization structure for the Intelligent Traffic Management System (ITMS).

```text
frontend/src/assets/
├── hero.png                 # Landing hero background illustration
├── route-planner/           # Smart Route Planner page assets (Phase 10)
└── shared/                  # Reusable icons, decorative illustrations, and logos
```

## Folder Descriptions

- **`route-planner/`**: Dedicated visual assets, map pin references, and routing markers for the Smart Route Planner.
- **`shared/`**: Common icons, logo elements, and shared graphics across pages.
